⚡ Alur Integrasi Cepat (Zero-Config)
  1. Unduh bundle client (ZIP) dari tombol di atas.
  2. Ekstrak ZIP di komputer client/kasir yang terinstall database PostgreSQL IPOS5.
  3. Jalankan setup.exe (klik kanan -> Run as Administrator).
  4. Pilih menu instalasi. Program akan otomatis mengarahkan port, membuat service Windows, dan menghubungkan tunnel.
  5. Otomatisasi Klon Awal: Begitu client terhubung ke tunnel, VPS akan langsung mendeteksi koneksi dan melakukan klon database pertama kali, lalu mengonfigurasi sinkronisasi Bucardo. Tidak diperlukan konfigurasi manual lebih lanjut!
