- `setup.exe`
- `nusatunnel-service.exe`
- `nusatunnel.exe`
- `nssm.exe`
- `pgbouncer.exe`
- `libevent-7.dll`
- `libssl-3-x64.dll`
- `libcrypto-3-x64.dll`
- `libwinpthread-1.dll`
- `pgbouncer.ini.tpl`
- `userlist.sample.txt`

Varian ini sengaja tanpa `nusatunnel-gui.exe`.
